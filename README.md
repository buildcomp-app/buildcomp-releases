# BuildComp 建物補償積算システム

CAD 図面から建物の補償額を算定するデスクトップアプリケーションの配布場所です。
JW_CAD を画面に組み込み、図面上の計測から算定書（Excel・24 様式）の出力までを一つの画面で行います。

## ダウンロード

**[最新バージョンはこちら](https://github.com/buildcomp-app/buildcomp-releases/releases/latest)**（現在 β 版）

最新バージョンのページの **Assets** からインストーラー（`BuildComp_Setup_<バージョン>.exe`）をダウンロードしてください。
機能・対応範囲・インストールの手順も同じページに記載しています。

## ご注意

- 利用にはライセンス（PC ごと）が必要です。ライセンスの無い PC では起動しません
- 動作環境：Windows 10 以降（64bit）
- ここにはインストーラーと自動更新用の案内のみを置いています（ソースコードは置いていません）
- 「バージョンの案内（自動更新用）」はアプリが更新の確認に使用するものです。ダウンロードは不要です
